From a record to a reasoned prediction

The same five steps run every time. The fourth is the Decision Tree itself; the others make sure it is only ever asked a fair question.

  1. Enter

    Fill in twelve values about the programme, the record so far and study habits.

  2. Validate

    Blank, non-numeric and out-of-range values are caught, with a message beside the field.

  3. Prepare

    Categories are encoded and GPA is rescaled, in the same column order used for training.

  4. Classify

    The saved tree asks one threshold question per node, from the root down to a leaf.

  5. Explain

    You get the class of result, the questions that led to it, and what to work on.
